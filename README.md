This is a weather application created by Jonathan Johnson, Renato Rako and Nedim Aydinci.
The application utilizes OpenWeatherMap API to get the coordinates and weather for a specified location by the user.

How to use:
Click on the location name in the center of the screen to search for a location you wish to know the weather of. 
You may also klick on the location pin to select a location from a map.
